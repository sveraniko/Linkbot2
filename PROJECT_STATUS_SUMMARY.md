## 🏗️ Архитектура проекта

### Структура каталогов
```
app/
├── handlers/           # Тонкий слой обработки Telegram событий
│   ├── ask.py         # Центральный ASK-модуль (1000+ строк)
│   ├── memory_panel.py # Панель управления памятью
│   ├── chat.py        # Чат-функциональность
│   └── ...
├── services/          # Бизнес-логика без Telegram-зависимостей
│   ├── ask_list.py    # Поиск и пагинация (subquery-distinct)
│   ├── ask_selection.py # Управление выбором источников
│   ├── ask_answer.py  # Формирование ответов
│   ├── llm_pipeline.py # LLM-вызовы с ретраями
│   ├── artifacts.py   # Управление артефактами
│   └── ...
├── utils/             # Утилиты
│   ├── markdown.py    # Централизованное экранирование
│   ├── tg.py         # Telegram-хелперы
│   └── ...
├── models.py          # ORM модели
├── states.py          # FSM состояния
└── config.py          # Конфигурация
```

### Ключевые компоненты

#### 1. ASK-модуль (`handlers/ask.py`)
- **1000+ строк кода** - центральный компонент системы

- **Панель иконок** - 💾📌🧾🔁📚🗑 всегда прикреплена к ответам
- **Поиск и пагинация** - 5 элементов на страницу

#### 2. Сервисный слой
- **ask_list.py** - поиск с subquery-distinct паттерном
- **llm_pipeline.py** - чистые LLM-вызовы без Telegram
- **ask_selection.py** - управление корзиной выбранных источников
- **artifacts.py** - сохранение и управление артефактами

#### 3. Управление состоянием
- **UserState.last_answer** - JSON с run_id, msg_ids, метаданными
- **Идемпотентность** - повторные клики не ломают систему
- **Валидация состояния** - проверка на входе каждого handler'а

## 🔧 Соответствие AntiFragile v3

### ✅ Реализованные инварианты

#### Safe Rendering & MarkdownV2 Escaping
- Централизованный `escape_markdown_v2()` в `utils/markdown.py`
- Альтернативный `escape_html()` для HTML-режима
- Никаких "мусорных" сообщений - только toast/всплывашки

#### UTF-8 Everywhere & Unicode Normalization
- PostgreSQL в UTF8 с client_encoding=UTF8
- Поиск через LOWER/ILIKE для корректной работы с кириллицей
- NFC нормализация (частично реализована)

#### Поиск/Выборка без дублей
- **Subquery-distinct паттерн** в `ask_list.py`
- Парсер терминов: `^\d+$` → id, `^#(.+)$` → тег, иначе → название
- Область проекта: active + linked projects
- Пагинация: ровно 5 элементов на страницу

#### Callback-data и неймспейсы
- Префиксы `ask:*` для всех ASK-колбэков
- Размер в пределах лимита Telegram (64 байта)
- Структурированные колбэки: `ask:answer:save:<run_id>`

#### FSM и роутинг
- ASK-роутер регистрируется первым
- Флаги-заглушки: `awaiting_ask_search=True`
- Состояния сбрасываются после шага

## 2. Соответствие инвариантам AntiFragile v3

### ✅ ВЫПОЛНЕНО

#### 2.1 Архитектурное разделение
- **Handlers тонкие**: Логика вынесена в сервисы
- **Services без Telegram**: Чистые функции без зависимостей от aiogram
- **Контракты четкие**: `list_sources()`, `toggle_selection()`, `run_llm_pipeline()`

#### 2.2 Роутинг и порядок
- **Правильный порядок**: ASK router регистрируется после keyboard, но до catch-all
- **Неймспейсы**: Все колбэки используют префиксы (`ask:*`, `aw:*`)

#### 2.3 Состояние (State v3)
- **Единая схема**: `last_answer` в JSON формате с версионированием
- **Поля добавлены**: `ask_armed`, `ask_inflight`, `ask_prompt_msg_id`, etc.
- **Миграции**: Все изменения через Alembic

#### 2.4 LLM Pipeline
- **Изолированный сервис**: `llm_pipeline.py` без Telegram зависимостей
- **Телеметрия**: События `llm_start`, `llm_done`, `llm_error`
- **Отключение**: Поддержка `LLM_DISABLED` флага

### ⚠️ ЧАСТИЧНО ВЫПОЛНЕНО

#### 2.5 Safe Rendering & Escaping
- **✅ Есть**: `escape_markdown_v2()` и `escape_html()` в `utils/markdown.py`
- **❌ НЕ ВЕЗДЕ**: В коде ASK handler'а используется `html.escape()` вместо централизованного
- **❌ ПРОБЛЕМА**: Не все сообщения проходят через единый экранировщик

#### 2.6 UTF-8 & Unicode Normalization
- **✅ Частично**: Есть обработка кодировок в импорте
- **❌ НЕ ВЕЗДЕ**: Нет явной NFC нормализации во всех точках ввода

#### 2.7 Поиск/Выборка
- **✅ Subquery-distinct**: Реализован в `ask_list.py`
- **✅ Парсер**: `parse_query()` обрабатывает `id/#tag/name`
- **✅ Пагинация**: 5 элементов на страницу
- **❌ ПРОБЛЕМА**: Область проекта не всегда корректно фильтруется

### ❌ КРИТИЧЕСКИЕ ПРОБЛЕМЫ

#### 2.8 "Чистый чат" нарушен
```python
# В ask.py найдены нарушения:
await message.answer("ASK-WIZARD открыт")  # Мусорное сообщение
await message.answer("Auto-clear переключен")  # Мусорное сообщение
await message.answer("Выбор очищен")  # Мусорное сообщение
```
**ТРЕБУЕТСЯ**: Заменить на `_toast()` или `answerCallbackQuery`

#### 2.9 Дублирование логики
- **ASK handler**: Содержит дублированную функцию `run_llm_pipeline()` в конце файла
- **Импорты**: Смешанные импорты сервисов и прямые SQL запросы в handlers

#### 2.10 Callback Data размеры
- **РИСК**: Некоторые callback_data могут превышать лимит 64 байта
- **НЕТ**: base64url кодирования для длинных параметров
